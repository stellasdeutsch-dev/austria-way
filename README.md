# Австрия: план поступления

Живая страница: **<https://stellasdeutsch-dev.github.io/austria-way/>**

Пошаговый план поступления в австрийский университет: Zulassung,
Aufenthaltsbewilligung, ÖH-Beitrag, Meldezettel. Работает целиком в браузере —
без сервера, без сети, без ключей API и без регистрации.

## Чем отличается от общего планировщика

Общий шаблон выдаёт всем один и тот же список шагов. Здесь план строится под
австрийские правила, и **гражданство меняет не текст, а состав шагов**:

| | ЕС / ЕЭЗ / Швейцария | Третья страна |
|---|---|---|
| Виза и пребывание до въезда | не нужны | Aufenthaltsbewilligung, до 3 месяцев, лично в представительстве |
| Подтверждение средств | не требуется | Richtsatz, со сроком хранения на счету |
| Регистрация | Anmeldebescheinigung в течение 4 месяцев после въезда | карта Aufenthaltstitel после приезда |
| Плата за обучение | обычно только взнос ÖH | Studienbeitrag + взнос ÖH |
| Срок подачи документов | общий | часто заметно раньше общего |

Из-за вида на жительство план для третьей страны длиннее и начинается раньше:
дедлайны считаются назад не от начала семестра, а от подачи на пребывание.

Семестры фиксированные: зимний с 1 октября, летний с 1 марта. Общий срок
подачи — 5 сентября и 5 февраля соответственно.

## Про точность

**Ни одна цифра здесь не является подтверждённым требованием конкретного вуза
или представительства.** Ставки Richtsatz, Studienbeitrag и взнос ÖH
пересматриваются ежегодно, сроки приёма у каждого вуза свои. Поэтому:

- суммы в тексте намеренно не названы там, где они меняются ежегодно;
- у каждого шага есть блок «Проверить в первоисточнике» со ссылкой на
  официальную страницу (oead.at, migration.gv.at, oeh.ac.at, oesterreich.gv.at);
- инструмент работает офлайн и **ничего не сверяет автоматически**.

Это шаблон типичной последовательности действий, а не юридическая консультация.

## Что умеет

- строить два разных плана в зависимости от гражданства;
- считать дедлайны назад от начала семестра, а для третьих стран — от подачи
  на вид на жительство;
- отмечать пункты чек-листов, редактировать, добавлять и удалять шаги;
- открывать каждый шаг отдельной страницей (`#/step/<id>`) с разбором:
  порядок действий, что подготовить, где обычно теряют время, ссылки на
  первоисточники;
- выгружать дедлайны в календарь (`.ics`) с напоминанием за неделю;
- экспортировать и импортировать план файлом, печатать в PDF;
- отвечать на вопросы поиском по данным самого плана — это правила, а не
  языковая модель.

## Запуск

Статические файлы, сборка не нужна.

```bash
python3 -m http.server 8080
```

## Структура

```
index.html
css/app.css
fonts/            Inter, три подмножества — локально, а не с Google Fonts
js/
  plan.js         фазы, генератор под австрийские правила, обратные дедлайны
  content.js      тексты шагов и проверенные ссылки на официальные источники
  store.js        localStorage: версия схемы, миграции, безопасная запись
  timeline.js     таймлайн, приоритеты, чек-листы, правка шагов
  stepview.js     страница отдельного шага
  assistant.js    чат по данным плана
  exporter.js     экспорт/импорт JSON, генерация .ics, печать
  app.js          точка входа: экраны, маршрутизация, форма, чат
```
